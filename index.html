Điền các tuỳ chọn cài đặt giống installer Subiquity, mọi thứ (kể cả hash mật khẩu) được tính ngay trong trình duyệt. Xong thì bấm tải file về.

Cần đổi mỗi lần: ★ Tài khoản & mật khẩu ★ SSH key ★ Mạng
01 — Ngôn ngữ & bàn phím
★ 02 — Mạng

Chọn DHCP nếu VPS/server tự cấp IP (đa số trường hợp). Chọn IP tĩnh nếu nhà cung cấp yêu cầu cấu hình thủ công.

"e*" khớp các tên kiểu eth0 / ens3 / enp0s3.
03 — Phân vùng đĩa

Dùng toàn bộ đĩa lớn nhất tìm được, theo layout mặc định của Subiquity.

★ 04 — Tài khoản
Tương đương lệnh: mkpasswd -m sha-512 — không có gì được gửi đi đâu, tính toán chạy hoàn toàn trên máy bạn.
★ 05 — SSH
Lấy key của bạn bằng: cat ~/.ssh/id_ed25519.pub
06 — Package & firewall
07 — Timezone, mirror & cập nhật
